# Portfolio Archive

**Archived:** October 4, 2025

This folder contains the original portfolio implementation before the refactor.
Use these files as reference when rebuilding components and pages.

## Structure

- `old-pages/` - Original page files (index, illustration, about, etc.)
- `old-components/` - Original Astro components (Header, Footer, etc.)
- `old-styles/` - Original SCSS files
- `old-scripts/` - Original JavaScript files (animations, carousels, etc.)

## Key Features to Reference

- **Image Gallery System** - `old-pages/illustration.astro`
  - Popup modal logic
  - Category switching
  - Responsive flex gallery layout
  
- **Navigation** - `old-components/Header.astro`
  - Hamburger menu
  - Active state handling
  
- **Animations** - `old-scripts/`
  - GSAP parallax effects
  - Carousel implementations

## Asset Organization

- `old-public/` - Original asset folders (illustration, dust, earthen, game-jams, narrative-work, etc.)
  - These have been archived to allow for a clean reorganization of assets in the new structure
  - Can reference these when setting up the new image data structure
