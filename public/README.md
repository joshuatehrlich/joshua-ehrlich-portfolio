# Public Assets

This folder contains static assets served directly by the web server.

## Current Structure

- `fonts/` - Custom web fonts
- `ui/` - UI icons and elements
- `favicon.jpg` & `favicon.png` - Site icons
- `Joshua-Ehrlich-Resume-2025.pdf` - Downloadable resume

## Future Asset Organization

When adding new assets, follow this structure:

```
public/
├── images/
│   ├── art/           # Gallery artwork
│   ├── projects/      # Project screenshots
│   └── about/         # About page images
├── videos/            # Video files
└── documents/         # PDFs and other documents
```

## Note

Old assets have been archived to `_archive/old-public/` for reference.
New assets should be organized in a cleaner structure as we rebuild.
